# Visualiser Studio 1.2.9

## Create and automation
- Arrange songs into named sections, each with its own style, colours and parameters.
- Drag section boundaries and crossfade handles, or choose an instant cut.
- Loop a selected region or an entire section while refining your visuals.
- Preview transitions, resize parameter tracks, and shape Blend curves with Alt-drag.
- Improved repeated-style continuity and restored transient response for Shatterfield and other styles.

## Controls and personalisation
- Consistent colour wheels and compact exact-value editors with styled number arrows.
- Smooth slider scrolling, fine adjustment and useful right-click actions.
- Settings search matches setting names.
- Sort Create styles by usage, name or the original order.
- Local statistics for listening time, exports and saved projects, with an animated time breakdown.
- Interface scaling, export filename/folder preferences and improved MIDI controls.

## Mac availability
- First public Mac downloads for Apple Silicon (arm64) and Intel (x64), requiring macOS 14.2 or newer.
- Mac audio capture, Spotify/Apple Music controls and Discord presence support.
- Mac installers use a local signature and are not Apple-notarized. After installing from the DMG, macOS may require System Settings → Privacy & Security → Open Anyway on first launch.
- Mac updates are manual for this release. Existing Mac Preview builds remain separate and do not update automatically.

## Downloads and updates
- Windows: Visualiser-Studio-Setup-1.2.9.exe.
- Apple Silicon: Visualiser-Studio-1.2.9-mac-arm64.dmg.
- Intel Mac: Visualiser-Studio-1.2.9-mac-x64.dmg.
- Windows automatic updates use only the Windows installer. Mac downloads never enter the Windows update feed.
- Projects and preferences are preserved when upgrading the installed Windows app.
