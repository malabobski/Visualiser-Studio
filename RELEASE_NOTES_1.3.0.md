# Visualiser Studio 1.3.0

## Community
- Sign in with Discord or Google and create your own profile.
- Find friends by username, send requests, and accept, decline, cancel or remove connections.
- Incoming requests appear on the Community sidebar icon and Requests tab. Startup notifications open Requests when clicked.
- A Community feed for text posts, shared Create looks and optional new-member introductions, with Everyone and Friends views.
- Save shared looks into Templates. Shared looks include visual settings; audio, MIDI files, automation, image layers and local file paths are excluded.
- Username changes have a one-calendar-month cooldown. Display names and bios remain editable.
- Quiet background updates preserve controls and drafts. New feed posts wait behind a button so reading doesn't jump.
- Login restores the app from the browser. Logout asks for confirmation.

## Stage Designer
- Add text, images and artwork to Create, with draggable, resizable layers.
- Place layers in front of or behind the visualiser, reorder them, and control opacity, timing and fades.
- Keep compositions in projects and templates and include them in exported videos.
- Dedicated playback scrolling: one-second steps, with Ctrl for fine adjustment.

## Remembered Live looks
- Remember a look for an artist or an individual song and recall it as the music changes.
- Manage, rename or remove remembered looks, choose a default and undo an automatic change.

## Downloads
- Windows: `Visualiser-Studio-Setup-1.3.0.exe`.
- Apple Silicon: `Visualiser-Studio-1.3.0-mac-arm64.dmg`.
- Intel Mac: `Visualiser-Studio-1.3.0-mac-x64.dmg`.
- Mac requires macOS 14.2 or newer. Builds use an ad-hoc signature and are not Apple-notarized; first launch may require **System Settings → Privacy & Security → Open Anyway**.
- Windows automatic updates remain Windows-only. Mac updates are manual; no Mac auto-update feed is published.
- Feed posts are visible to signed-in Community members. The Friends filter changes the view, not a post's visibility. Signup introductions are off by default.
